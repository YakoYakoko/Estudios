Conceptos clave:
- Shodan: Motor de búsqueda para IoT e infraestructura. Escanea internet buscando equipos de red, cámaras, servidores web, etc.
- VirusTotal: Pasa filtros de múltiples antivirus a la vez para verificar que URLs, dominios, IPs o archivos no sean maliciosos.
- CVE: Registro público y diccionario universal de vulnerabilidades / fallos de seguridad conocidos en software y hardware (no solo virus).
- Documentación oficial: Manuales técnicos para entender el uso exacto de comandos, protocolos y errores.

Comandos y filtros clave:
- Filtros de Shodan (Dorks): `country`, `port`, `org`, `hostname` (para filtrar por país, puerto abierto, empresa u host).
- `nc host.example.com 42`: Abre conexión TCP directa con el puerto 42 usando Netcat.
